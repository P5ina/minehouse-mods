# MineHouse Trailer

Клиентский мод, который снимает 30-секундный трейлер сервера в одиночном мире. Ставится только
себе (Fabric, Minecraft 26.3, Fabric API), на сервер не нужен.

Всё, что двигается, живёт только у вас в клиенте: NPC (манекены со скинами), метеорит, камера,
время суток. Декорации, которым нужны настоящие блоки (костёр, руда, кратер, бассейн, ферма,
столб), ставятся в мир на время своего кадра и убираются после него. Мир лучше взять отдельный,
моковый.

## Как снять

1. Создайте новый мир с читами (режим любой), найдите ровную поляну без построек, примерно 50 блоков
   во все стороны.
2. `/trailer stage` — сцена здесь. Спавн с толпой будет в этой точке, метеорит упадёт в 38 блоках
   на северо-восток, бассейн, ферма, шахта и дуэль раскиданы вокруг.
3. Музыка (по желанию): `/trailer music` создаст пакет ресурсов «MineHouse Trailer Music» и скажет,
   куда положить `music.ogg`. Трек обрежьте так, чтобы дроп был на 15.24 с от начала:
   `ffmpeg -ss <дроп минус 15.24> -t 33 -i трек.mp3 -c:a libvorbis -q:a 6 music.ogg`.
   Включите пакет в настройках.
4. Запустите запись в OBS, в игре `/trailer play`. Две секунды чёрного экрана, потом 30.5 с
   трейлера, в конце всё возвращается (режим игры, блоки).
5. `/trailer play 9` — с 9-го такта, чтобы проверить кусок (без музыки). `/trailer stop` — прервать.

Мод сам переводит вас в наблюдателя, выключает погоду, спавн мобов и случайные тики
(`random_tick_speed 0`), прячет интерфейс и рисует титры, вспышку и финальную карточку с IP и Discord.
Камера и смена кадров идут по реальным часам и стартуют, когда звук действительно заиграл, поэтому
склейки попадают в бит при любом FPS.

Скины NPC: по умолчанию девять стандартных. Можно вписать ники в `config/minehouse-trailer.json`,
поле `skins` (скины подтянутся с серверов Mojang).

## Раскадровка (126 BPM, такт 1.905 с)

| Такты | Кадр |
| --- | --- |
| 1-2 | Рассвет, пролёт к спавну, люди гуляют, титр MINEHOUSE |
| 3-4 | День, пятеро идут по поляне, камера едет рядом |
| 5-6 | Золотой час, двое копают алмазы, камера облетает |
| 7 | Ночь, костёр на спавне |
| 8 | Разгон по долям: ставят блок, ломают руду, метеорит в небе, лицо смотрит вверх |
| 9 | Дроп: удар метеорита, вспышка, тряска, «Ивенты для всего сервера» |
| 10 | Толпа вокруг кратера |
| 10.5-13 | По полтакта: элитры, дуэль, прыжок в воду, растёт пшеница, танец, столб, машут в камеру |
| 14-15 | Кран вверх от толпы над миром |
| 16 | Финальная карточка: play.minehouse.pro и Discord |

Кадры описаны в `Trailer.buildShots()`: у каждого время суток, что ставится в мир, что делают
NPC и где камера. Координаты считаются от точки сцены.

## Сборка

```
./gradlew build                          # jar в build/libs
xvfb-run ./gradlew runSelftestClient     # новый мир, весь трейлер, скриншоты в run-selftest/screenshots
```
