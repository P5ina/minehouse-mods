# MineHouse Zones Client

Клиентский Fabric-мод для сборки MineHouse. Рисует границы зон спавна линиями и
полупрозрачными стенами вместо частиц.

## Зачем

Зоны спавна живут в [MineHouse Bank](../bank-mod) (пакет `zones`). Когда админ держит палку
«Разметка зон» или игрок пишет `/zones show`, сервер показывает границы. Без мода это
частицы на высоте игрока. С модом сервер присылает пакет `minehouse:zone_shapes` с
многоугольниками, и клиент рисует:

- полупрозрачную стену по каждой стороне зоны, от нижней до верхней высоты зоны;
- сплошные линии снизу и сверху, тонкие каждые 10 блоков и линию на уровне ног игрока;
- столбы в углах и название зоны над серединой;
- у черновика админа (фиолетовый) пронумерованные вершины.

Цвета как на сайте и BlueMap: оранжевая — аукцион, зелёная — свободна, красная — арендована,
бирюзовая — твоя, белая — общая. Дальше 160 блоков ничего не рисуется.

Рисуется ванильными гизмо (`net.minecraft.gizmos`), без миксинов. Сервер узнаёт о моде по
зарегистрированному каналу (Fabric API) и шлёт пакет только когда набор зон меняется. На
других серверах мод ничего не делает.

## Как устроено

- `ZoneShapesPayload`: пакет со списком зон, такой же класс лежит в `bank-mod`.
- `ZoneRenderer`: каждый тик кладёт линии, стены и подписи в `Minecraft.collectPerTickGizmos()`.
- `SelfTest`: проверка для CI.
- `Demo`: только для разработки, рисует выдуманные зоны и делает скриншот.

## Сборка и проверка

```sh
./gradlew build                 # jar
xvfb-run ./gradlew runSelftestClient   # пакет, кодек и отрисовка, печатает MINEHOUSE_ZONES_CLIENT_OK
```

Посмотреть картинку: запусти любой сервер 26.3 на localhost:25565 (`./gradlew runServer`,
`online-mode=false`, `white-list=false`, Steve в `ops.json`), потом `./gradlew runDemoClient`.
Скриншоты лягут в `run-demo/screenshots/`.

После изменений пересобери и положи jar в сборку:
`./gradlew build && cp build/libs/minehouse-zones-client-*.jar ../modpack/minehouse-zones-client.jar`
