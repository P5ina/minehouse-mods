# MineHouse Anvil Client

Клиентский Fabric-мод для сборки MineHouse. Показывает в окне наковальни настоящую цену
работы вместо 39 и без «Слишком дорого!».

## Зачем

На сервере стоит [MineHouse Anvil](../anvil-mod): у наковальни нет лимита в 40 уровней.
Ванильный клиент при цене от 40 пишет «Слишком дорого!», поэтому сервер отправляет ему
не больше 39, а настоящую цену пишет над хотбаром. С этим модом сервер присылает
настоящую цену пакетом `minehouse:anvil_cost`, и она видна прямо в окне: «Требуемый
уровень: 58», красным, если уровней не хватает. Надписи над хотбаром тогда нет.

Сервер узнаёт о моде по зарегистрированному каналу (Fabric API), игрокам без мода всё
работает как раньше. На других серверах мод ничего не меняет: пакет не приходит, окно
ванильное.

## Как устроено

- `AnvilCostPayload`: пакет (id окна, цена), такой же класс лежит в `anvil-mod`.
- `AnvilCost`: последняя цена от сервера. Ей верим, только пока в окне стоит то, во что
  сервер её урезал (`min(цена, 39)`): сразу после перекладывания предметов клиент сам
  пересчитывает цену по ванильным правилам, и до ответа сервера показывается она.
- `AnvilScreenMixin`: в `extractLabels` подменяет цену, убирает порог 40 и считает цвет по
  настоящей цене.

## Сборка и проверка

```sh
./gradlew build                 # jar + юнит-тесты
xvfb-run ./gradlew runSelftestClient   # применяет все миксины, печатает MINEHOUSE_ANVIL_CLIENT_OK
```

В сборке лежит собранный jar `modpack/minehouse-anvil-client.jar` (CI проверяет, что он
совпадает с исходниками). Поменял мод: `./gradlew build && cp build/libs/minehouse-anvil-client-*.jar ../modpack/minehouse-anvil-client.jar`
и подними `version` в `modpack/pack.json`. Требует Fabric API (он и так есть в сборке).
